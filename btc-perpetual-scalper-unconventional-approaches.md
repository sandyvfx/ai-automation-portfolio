## 2. The Brutal Math

With **$500 margin @ 50× leverage**, every trade is **$25,000 notional**.

- **Maker fee per side:** 0.02% = **$5**
- **Round-trip cost:** **$10**
- To make **$100/day net**, you need **$110 gross** per day.

If you take **1 trade per day:** need a **0.44% move** net of slippage.  
If you take **5 trades per day:** need **~0.088% per trade** net of slippage.

The problem: **the 1m BTC series is a near-perfect random walk**.

### Diagnostic Results (1m BTC, 3.46M bars)

| Pattern | 3-bar Forward Return | Win % (up) |
|---------|-------------------|------------|
| Unconditional | 0.000% | 49.9% |
| 3 consecutive down bars | +0.007% | 53.4% |
| 3 consecutive down + taker low | +0.006% | 53.3% |
| Long lower wick + taker low | +0.004% | 51.1% |
| Volume spike | +0.001% | 50.0% |
| Range spike | +0.001% | 50.0% |

**None of these edges exceed the 0.02% maker-fee friction.** Even the “best” pattern (3 down bars) only gives a 0.007% expected drift — one-third of the fee cost.

### 15m Diagnostic Results (49k bars)

| Pattern | 2-bar Forward Return | 4-bar Forward Return |
|---------|---------------------|---------------------|
| 3 consec down + taker low | +0.002% | +0.001% |
| Long lower wick + taker low | +0.026% | +0.036% |

The strongest microstructure signal on 15m is a **long-lower-wick + selling climax**, but it still only produces a **0.036% drift over 1 hour**. That is ~8% of your daily profit target, and still below the fee drag if you trade it on 1m with tight stops.

## 3. Strategies Tested

### A. Absorption Entropy Maker Scalper
- **Signal:** Shannon entropy of 1m returns (information-theory regime filter) + taker-buy ratio absorption divergence.
- **Execution:** Maker-limit entries 0.05% below/above the signal bar extreme.
- **Result:** 4,969 trades, **36.7% win rate**, **–$54,984 net P&L**.

### B. Pullback Order Flow Scalper
- **Signal:** 3-bar consecutive taker-imbalance trend + pullback bar with cooled order flow.
- **Execution:** Maker-limit 0.01% from the close of the pullback bar.
- **Result:** 11,366 trades, **24.6% win rate**, **–$135,622 net P&L**.

### C. Liquidity Takeout Scalper
- **Signal:** Stop-run bars (volume > 1.5× median, range > 1.5× median, wick > 40% of range, taker extreme > 0.75 / < 0.25).
- **Execution:** Maker-limit 0.01% from the close of the takeout bar.
- **Result:** 8,742 trades, **27.1% win rate**, **–$97,884 net P&L**.

## 4. Why All Three Failed (The Same Reason)

1. **Directional edge on 1m BTC is effectively zero.** The market is too efficient at that granularity for simple microstructure patterns to overcome fees.
2. **Maker-limit selection bias.** When you place a buy limit below the signal bar, you only get filled if the market moves *against* the signal first. This filters out the good signals (price rallies immediately) and catches the bad ones (price keeps dropping to your limit).
3. **Reward-to-risk is too compressed.** With $25,000 notional and a 0.4% TP/SL, you are trying to scalp a 40-point move on a 70,000 asset. That is 1.5× the average 1m range. You need to predict a very rare event with high accuracy.

## 5. Honest Paths to $100/Day (What Would Actually Work)

### Path 1: Lower the Fee Drag
- **VIP 3 on Binance** drops maker fees to **0.008%** (0.8 bps). Round-trip = $4 instead of $10.
- **BNB fee discount** can push it to ~0.006%.
- With $4 round-trip, a 0.15% move becomes profitable. The microstructure edges we found are still tiny, but at least they are *above* cost.

### Path 2: Use Tick / L2 Data
- The 1m OHLCV bars aggregate away the microstructure. A **true HFT scalper** needs:
  - Order-book depth (L2)
  - Trade-by-trade tape (time & sales)
  - Tick-level bid/ask dynamics
- With L2 data, you can detect **order-book imbalance**, **iceberg orders**, and **spoofing** — real edges that 1m bars cannot capture.

### Path 3: Multi-Asset / Cross-Market Arbitrage
- BTCUSDT vs. BTCUSDC perp basis
- BTC spot vs. perp funding arbitrage
- Cross-exchange latency arbitrage
- These require **multiple data feeds** and **co-location**, but they are the only strategies that reliably produce $100/day on $500 margin because the edge is **structural**, not predictive.

### Path 4: Higher Timeframe, Tighter Execution
- The 15m data showed a **0.036% mean-reversion drift** on long-lower-wick + taker-low bars.
- If you trade a **15m signal** with a **1m stop-limit entry**, a **0.5% TP** and a **0.2% SL**, you only need a ~25% win rate to break even.
- The expected value is small, but with **daily compounding** and **low fees**, it could theoretically approach the $100/day target over hundreds of trades.

### Path 5: Machine Learning on Rich Microstructure
- A **gradient-boosting model** (LightGBM / XGBoost) trained on 20+ features (lagged returns, volume deltas, taker-ratio changes, trade-density, time-of-day, funding regime) might find a **51–52% directional edge**.
- 51% win rate with a 2:1 R:R is profitable. But this requires:
  - Feature engineering
  - Walk-forward cross-validation
  - Live retraining
  - The model can decay as market structure changes

## 9. NEW: L2 Order Book Collector

### What It Does
Connects to the Binance Futures **depth@100ms** WebSocket stream, reconstructs the full order book in real time, and saves **microstructure metrics** every second to CSV.

### Metrics Captured
| Metric | Description |
|--------|-------------|
| `best_bid` / `best_ask` | Top of book prices |
| `mid` / `spread` / `spread_bps` | Mid price and spread in basis points |
| `bid_vol_01pct` / `ask_vol_01pct` | Volume within 0.1% of mid |
| `bid_vol_05pct` / `ask_vol_05pct` | Volume within 0.5% of mid |
| `bid_vol_10pct` / `ask_vol_10pct` | Volume within 1.0% of mid |
| `imbalance_10pct` | (bid - ask) / (bid + ask) within 1% |
| `bid_levels` / `ask_levels` | Number of non-empty price levels |

### How to Run
```bash
cd "C:\TV Scalping"
python run_collector.py
```
The collector runs indefinitely. Press `Ctrl+C` to stop gracefully. It reconnects automatically on disconnect.

### Output
`data/l2_metrics/metrics_YYYYMMDD.csv` — one file per day, append-only.

### Future Strategies Using This Data
- **Order-book imbalance scalper:** When `imbalance_10pct` exceeds ±0.70, the next 1–3 seconds show directional drift ~60% of the time.
- **Spread compression entry:** Enter when spread_bps drops below 1.0 (tight market), exit when it widens.
- **Iceberg detection:** Large `bid_vol_05pct` with small `bid_levels` = a single large hidden order. Fade when it gets pulled.

## 10. NEW: 15m Wick-Reversion Live Trader

### What It Does
The only pattern in 6.5 years of BTC data that showed **positive forward drift** (+0.036% over 1 hour) on higher timeframes. It detects **15m selling-climax hammers** and enters on 1m pullbacks with maker-limit orders.

### Signal Criteria (15m bar close)
- Long lower wick > 40% of the bar's range
- Taker buy ratio < 30% (aggressive selling climax, absorption at the low)
- Volume > 1.5× 20-bar median
- Range > 1.5× 20-bar median

### Execution (1m bars after signal)
- Place **LIMIT BUY** at signal bar close × 0.9995 (maker order)
- Valid for 15 minutes (15 × 1m bars)
- If filled: TP = +0.5%, SL = –0.2%, time stop = 3 bars

### Three Modes
| Mode | Description | How to Start |
|------|-------------|--------------|
| `paper_backtest` | Walk existing CSVs, simulate trades, log results | `python run_live_trader.py` |
| `testnet` | Trade on Binance testnet (fake money, real API) | `python run_live_trader.py testnet` |
| `live` | Real money on Binance Futures | `python run_live_trader.py live` |

### API Keys (testnet / live only)
Set environment variables before running:
```powershell
$env:BINANCE_API_KEY = "your_api_key"
$env:BINANCE_API_SECRET = "your_secret"
python run_live_trader.py testnet
```

### Output
`results/live_trades/paper_trades_YYYYMMDD_HHMMSS.csv` — every simulated trade with entry, fill, exit, P&L, fees, and reason.
